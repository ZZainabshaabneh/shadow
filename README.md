# Shadow Game

🎮 A game project developed using Unity and C#

## Project Overview
A simple game built with Unity Engine using C#. The player controls a character that moves in a 3D environment. The project demonstrates object-oriented programming (OOP) principles, physics interactions, and movement logic within a game context.

## Technologies Used
- Unity Engine
- C# (Mono/.NET)
- Unity UI Tools

## Project Goals
- Apply C# programming concepts in an interactive environment.
- Develop game logic including character movement and collisions.
- Understand Unity project structure, scene management, and component-based development.

## How to Run the Game
1. Make sure [Unity Hub](https://unity.com/download) and Unity Editor (preferably the version used in development) are installed.
2. Open Unity Hub.
3. Click "Open Project" and select the project folder.
4. Open the main scene (e.g., `Main Scene`).
5. Click the Play button (▶️) to start the game.
